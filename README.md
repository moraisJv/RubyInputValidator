#  Ruby Input Validator

A lightweight Ruby script designed to validate user input safely. It checks name length and restricted characters using Regular Expressions (Regex), followed by an age verification check with clean control flow structures.

---

##  Features

- **Length Validation**: Ensures names do not exceed character limits.
- **Regex Pattern Matching**: Prevents special characters and symbols in name inputs.
- **Age Verification**: Converts input string to integer (`.to_i`) to check user age eligibility.
- **Clean Methods**: Structured cleanly using Ruby's `def` and conditional logic (`if/elsif/else`).

---

## Tech Stack

- **Language**: Ruby
- **Tools**: Terminal / IRB / JetBrains RubyMine
